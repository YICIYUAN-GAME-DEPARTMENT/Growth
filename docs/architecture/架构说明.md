# 架构说明

> 配套主文档：[docs/开发文档.md](../开发文档.md) §2。本文展开分层、Autoload、事件总线、资源管理与场景编排的实现细节。

## 1. 分层职责

```
Autoload 单例（全局生命周期，跨场景存活）
   ├ GameManager      状态机 / 分数 / 场景流转 / 暂停
   ├ EventManager     信号总线（解耦）
   ├ ResourceManager  场景与资源的登记/缓存
   └ AudioManager    BGM / SFX 播放
Systems（玩法系统，由场景持有，不全局）
Entities（玩家/敌人/拾取物，挂 WorldRoot）
Scenes（编排层）
Resources（数据/配置）
```

**依赖方向：** Autoload ← Systems ← Entities ← Scenes ← Resources。**禁止反向依赖**：Autoload 不引用具体玩法类，Entities 不直接调 Systems。

## 2. Autoload 单例

| 单例 | 文件 | 职责 | 对外接口（稳定，勿擅改） |
|------|------|------|---------------------------|
| `GameManager` | `Scripts/Autoload/GameManager.gd` | 顶层状态、场景切换、暂停、分数 | `change_scene()` `pause_game()` `resume_game()` `end_game()` `add_score()` |
| `EventManager` | `Scripts/Autoload/EventManager.gd` | 全局信号总线 | 各 `signal`（见文件底部 Grow Hook 区可扩展） |
| `ResourceManager` | `Scripts/Autoload/ResourceManager.gd` | 资源登记与缓存 | `register_scene()` `get_scene()` `register_resource()` `get_resource()` `prewarm()` |
| `AudioManager` | `Scripts/Autoload/AudioManager.gd` | BGM/SFX 播放 | `play_sfx()` `play_music()` `stop_music()` |

所有单例已在 `project.godot` 的 `[autoload]` 段登记，代码中直接以类名调用，如 `GameManager.change_scene("res://Scenes/Levels/LVL_Forest_01.tscn")`。

## 3. 事件总线

- **定义点：** 所有跨系统信号集中声明在 `EventManager`。
- **使用：** 发送方 `EventManager.score_changed.emit(score)`；接收方 `EventManager.score_changed.connect(_on_score_changed)`。
- **命名：** 信号名用过去式或状态名词（`game_over`、`health_changed`），参数显式标类型。
- **扩展：** Grow 玩法冻结后新增信号追加到 `EventManager` 末尾"Grow 主题 Hook"区块，**勿删改既有信号签名**。

## 4. 资源管理

### 4.1 登记时机
- 启动期资源：`MainMenu._ready()` 或新建 `BootStrap.tscn` 统一登记。
- 关卡期资源：关卡场景 `_setup()` 中登记本关用到的资源。

### 4.2 异步预热
对大资源（BGM / 大贴图）用 `ResourceManager.prewarm(paths)` 后台加载，使用前 `is_prewarmed(path)` 取回，避免主线程卡顿。

## 5. 场景编排

### 5.1 Main.tscn
根场景，节点树见主文档 §4.3。玩法场景通过 `ResourceManager.get_scene(id).instantiate()` 后 `add_child(world_root)`。

### 5.2 GameScene 生命周期
```
_ready() → _setup() → _on_scene_entered()
... 运行 ...
exit_to(target) → _on_scene_exiting() → GameManager.change_scene()
```
子类只重写三个虚函数，无需关心切换细节。

### 5.3 UI 层
- HUD / 菜单挂 `UIRoot`（CanvasLayer），`layer` 默认 1。
- 暂停覆盖层 `process_mode = PROCESS_MODE_WHEN_PAUSED`。

## 6. 输入
- 输入动作在 `project.godot` 的 `[input]` 段集中定义（`move_*` `interact` `pause` `ui_*`）。
- 业务代码用 `Input.is_action_pressed("move_up")` 等，**禁止**裸查键码。

## 7. 物理层
`project.godot` 已命名 2D 物理层：
`1=World 2=Player 3=Enemy 4=Projectile 5=Trigger`。实体按归属设置 `collision_mask`/`collision_layer`，避免数字裸写。
