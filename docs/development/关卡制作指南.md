# 关卡制作指南（场景直编）

> 目标：设计者 5 分钟内新建一关并试玩。不写任何数据文件——关卡就是一个场景。
> 规则/数值权威：[功能需求文档](../design/功能需求文档.md)；工程细节：[开发文档](../开发文档.md) §4/§5。

## 1. 新建关卡

1. 在 Godot 编辑器 FileSystem 中 **复制** `Scenes/Levels/LevelTemplate.tscn`。
2. 粘贴到同一目录并重命名：`Level_<序号>_<名字>.tscn`（例如 `Level_02_Slalom.tscn`）。
3. 双击打开该场景。

> LevelSelect 启动时自动扫描 `Scenes/Levels/Level_*.tscn`（以 `Level_` 开头的才会出现在选关列表）。

## 2. 摆放内容

在 `Level_xx` 根节点下（拖入/复制以下预制即可），所有实体**拖动到格子上会自动吸附**（编辑器开启吸附更顺滑：场景右键 → Snap → 勾选 Grid，Grid Step 设 32）：

| 实体 | 预制 | 说明 |
|------|------|------|
| 出生点 | `Scenes/Entities/PlayerSpawn.tscn` | 每关**恰好 1 个**（主角尾部锚点 S） |
| 障碍 | `Scenes/Entities/Obstacle.tscn` | 每格放一个（可用 Ctrl+D 快速复制） |
| 食物 | `Scenes/Entities/Food.tscn` | 越多 L 增长机会越多 |
| 终点 | `Scenes/Entities/Goal.tscn` | 每关 1 个，头部到达即胜 |
| 机关 | `Scenes/Entities/Mechanism.tscn` | 摆 1 个 = 机关核心；内部含 5 阶段预览，运行时按 lv 自绘 |

## 3. 根节点设置（Inspector）

| 导出 | 说明 |
|------|------|
| `level_id` | 唯一编号（选关排序 & 步数记录 key） |
| `level_name` | 选关界面显示名 |
| `map_size` | 保底地图尺寸（默认 32×32）；不必精确，运行时自动扩到覆盖全部实体 |

## 4. 全局数值（随手可调）

- 打开 `Resources/Config/Balance.tres`，在 Inspector 直接修改：
  - `initial_max_len`（初始最大身长 L）
  - `food_len_gain`（吃食物 ΔL）
  - `growth_step_interval`（每走几步机关长一次）
- 无需改代码，重跑游戏即生效。

## 5. 试玩与校验

1. 直接 **F5** 从 MainMenu 进入选关即可玩到你的关。
2. 发布前逐条对照 [功能需求文档](../design/功能需求文档.md) §6.3 / §8：
   - 出生点 BFS 能到终点（关卡内放错会开局判失败并弹"无路可走"，便于发现）；
   - 按 L 硬上限存在"吃食物逐段可达终点"的食物链；
   - 教程关需有引导。

## 常见问题
| 现象 | 处理 |
|------|------|
| 开局就"无路可走" | 出生点到终点被 Obstacle 或机关挡住，或缺 Goal/Spawn |
| 走不到远处 | L 硬上限限制步长：需要沿途放足够的 Food 拉长 L |
| 拖动不吸附 | 打开编辑器网格吸附（Snap → Grid 32px），或直接在 Inspector 输入 `cell` |
| 选关列表没有新关 | 文件名必须以 `Level_` 开头并放在 `Scenes/Levels/` |
