# 关卡制作指南（场景直编 · TileMap 涂格）

> 目标：设计者 5 分钟内新建一关并试玩。不写任何数据文件——关卡就是一个场景。
> 规则/数值权威：[功能需求文档](../design/功能需求文档.md)；工程细节：[开发文档](../开发文档.md) §4/§5。
> UI/贴图/布局全部用编辑器场景树组织；脚本不画画面、不建控件。

## 1. 新建关卡

1. 在 Godot 编辑器 FileSystem 中 **复制** `Scenes/Levels/LevelTemplate.tscn`。
2. 粘贴到同一目录并重命名：`Level_<序号>_<名字>.tscn`（例如 `Level_02_Slalom.tscn`）。
3. 双击打开该场景，按 §5 设置根节点导出。

> LevelSelect 启动时自动扫描 `Scenes/Levels/Level_*.tscn`（模板 `LevelTemplate.tscn` 已被代码排除，不会出现在列表）。**新关必须以 `Level_` 开头并放到该目录**才会被收录。

## 2. 场景树里有什么（先认识）

```
Level (Level.gd 只做规则)
├─ World  (Node2D)  内容容器（随你摆；通常放 (0,0)，脚本不动它）
│  ├─ Ground        TileMapLayer  ← 涂地板；运行时只在你涂的区域里兜底填洞
│  ├─ Obstacles     TileMapLayer  ← ★ 涂障碍（涂上的格=不可走）
│  ├─ EntityRoot
│  │  ├─ PlayerSpawn / Goal / Food ×N / Mechanism ×N
│  ├─ MechanismCells  TileMapLayer（机关生长体，运行期自动同步，勿手改）
│  ├─ PlayerCells     TileMapLayer（玩家管道：中段连接件 + 头/尾格端点半截瓦，运行期自动同步，勿手改）
│  └─ PlayerFx        Node2D（头/尾独立 Sprite：Head 跟 head（精灵表 4 行方向×3 帧选片、不旋转，z 高于 Tail）、Tail 固定 S 按方向旋转，起步即显示、头可叠尾上；运行期驱动，勿手改）
├─ LevelHUD（顶栏+结算，已实例化，勿改结构）
└─ Cam（Camera2D，你想放哪放哪；脚本运行时不移动、不缩放）
```

> **位置规则（所见即所得）**：脚本在运行时**不会**移动 World、不会移动/缩放 Camera——
> 编辑器里怎么摆，游戏就怎么显示。**地板=可走区**：玩家/机关只在 `Ground` 实际涂的格子上活动，
> 涂成什么样游戏就是什么样（Ground 未涂=背景，不进地图可走范围）。
> 想让地图出现在窗口左上角：把 World 放 (0,0)、把 Cam 摆在你要的位置即可。

## 3. 涂格子（关键操作）

- 每层已配好独立 Terrain TileSet（**三套都是 47-blob，按 8 邻接自动贴边**）：`Ground`=地板 `TerrainGrassBlob47.tres`、`Obstacles`=墙 `TerrainWall.tres`、`MechanismCells`=机关体 `TerrainMech.tres`（机关层运行期自动同步，编辑期通常无需涂）——涂满一块边缘/转角会自动平滑，无需手动拼图。
- **选对层再画（用 Terrain 画笔）**：
  1. 点选场景里的 `Ground` 层 → 工具栏切到 **Terrain 模式**，用**地板地形**涂出**可走区**（**地板=可走区**：只涂你想要的形状即可，Ground 未涂的格=背景不可走；blob 地板运行时**不会再**把包围盒内空格外扩成矩形）。地图范围（机关越界判定的矩形）=你涂的格+实体的包围盒。
  2. 点选 `Obstacles` 层 → 同样用 Terrain 画笔，涂想要挡路的格（被涂格=不可走）。
- 画错/擦除：TileMap 层上按住 **Shift 拖**（擦除）或用橡皮。
- 建议开编辑器网格吸附：菜单 Scene → Snap → 勾选 Snap、Grid Step 设为 32，方便拖实体对齐。
- 换正式美术：**地板/墙/机关均为正式 47-blob**——地板 `Art/Tiles/TILE_Grass_Blob47_01.png`（1504×32，Ground 在用 `TerrainGrassBlob47.tres`）、墙 `Art/Tiles/TILE_Wall_Blob47__01.png`（1504×32，Obstacles 在用 `TerrainWall.tres`）、机关花 `Art/Tiles/TILE_Flower_Blob47_Animated_01.png`（1504×96 三帧行，MechanismCells 在用 `TerrainMech.tres`），三套 corners+sides、列序一致（见 [开发文档](../开发文档.md) §4.4 贴图替换契约）——**已画地图会自动换皮，无需重画**（旧场景 Obstacles 若按 4 角存格，Level.gd 运行期按实际涂格自动重涂成 blob）；旧关卡若还在用 16 列地板（`TerrainFloor.tres`），把该关 `Ground` 层的 TileSet 换成 `TerrainGrassBlob47.tres` 即可（Level.gd 运行时按瓦片集模式自动重涂）。

## 4. 放实体（只拖预制，不改属性以外的东西）

从 `Scenes/Entities/` 拖到 `Level/EntityRoot` 下，拖动即吸附格子：

| 实体 | 预制 | 说明 |
|------|------|------|
| 出生点 | `PlayerSpawn.tscn` | 每关**恰好 1 个**（主角尾部锚点 S，运行时自动隐藏标识） |
| 食物 | `Food.tscn` | 放食物（单贴图）；越多 L 增长机会越多 |
| 终点 | `Goal.tscn` | 每关 1 个，头部到达即胜 |
| 机关 | `Mechanism.tscn` | 放 1 个 = 机关核心 C（Core 单贴图）；生长体运行时自动涂到 MechanismCells（含核心格，核心由 Core 贴图浮在瓦片上层）。机关**只在已涂地板上**占位（Ground 未涂=背景不可走也不长机关；越界跳过）——核心与生长方向请放在已涂地板里 |

## 5. 根节点设置（Inspector）

| 导出 | 说明 |
|------|------|
| `level_id` | 唯一编号（选关排序 & 步数记录 key） |
| `level_name` | 选关界面显示名 |
| `map_size` | **仅当场景完全空白时的保底尺寸**（默认 32×32）；一旦涂了地板/放了实体，地图范围自动取内容的包围盒 |
| `initial_max_len_override` | **0=沿用全局** L；>0 本关覆盖初始身长 |
| `food_len_gain_override` | 0=沿用全局；>0 本关覆盖食物 ΔL |
| `mechanism_max_level_override` | 0=沿用全局；>0 本关覆盖机关最高阶段（0–4） |
| `growth_step_interval_override` | 0=沿用全局；>0 本关覆盖机关生长周期 |

> **生长动画时长**（`grow_anim_sec`）只放在全局 Balance，不在关卡里。

## 6. 数值（全局基准 + 单关覆盖）

- **全局基准**：打开 `Resources/Config/Balance.tres` 在 Inspector 直接改 `initial_max_len` / `food_len_gain` / `mechanism_max_level` / `growth_step_interval` / `grow_anim_sec`。
- **单关覆盖**：选中关卡根节点 `Level`，把上面 4 个 `*_override` 填成你要的值（填 0 就表示"这关沿用全局"，调全局即生效）。
- 无需改代码，重跑游戏即生效。

## 7. 试玩与校验

1. 直接 **F5** 从 MainMenu 进入选关即可玩到你的关。
2. 发布前逐条对照 [功能需求文档](../design/功能需求文档.md) §6.3 / §8：
   - 出生点 BFS 能到终点（开局即弹"无路可走"= 布局有问题）；
   - 按 L 硬上限存在"吃食物逐段可达终点"的食物链（食物要放在当前 L 能到的地方）；
   - 教程关需有引导。

## 常见问题
| 现象 | 处理 |
|------|------|
| 开局就"无路可走" | Obstacles 涂格挡住了 S→E，或缺 Goal/Spawn |
| 地图外出现一大片地板 | 地图范围=你涂的格+实体的包围盒；全空白才会退回 `map_size`(默认32×32)。若已涂却仍很大，检查是否有远离主区的零散涂格/实体把包围盒撑大 |
| 机关长不大/长出去的地板消失了 | 机关**只在已涂地板（可走区）上**占位：Ground 未涂=背景不可走也不长机关；越过包围盒/无地板的格会跳过。核心与生长方向都放在已涂地板里，并预留生长空间 |
| 机关满级后好像"不长了" | 满级阶段不变，但**每次到生长周期仍会刷新**：你身体之前挡住的格，只要你离开，下次生长就会补占（阶段不会退回） |
| 走不到远处 | L 是硬上限：沿途要多放 Food 拉长 L |
| 拖实体不对齐 | 开编辑器网格吸附（Snap → Grid 32px）或直接在 Inspector 填 `cell` |
| 选关列表没有新关 | 文件名必须以 `Level_` 开头并放在 `Scenes/Levels/`（`LevelTemplate` 会被排除） |
| 机关不显示形状 | 机关=核心贴图+生长体同步层，默认 lv0 只有核心；走够步数后生长体自动涂出 |
