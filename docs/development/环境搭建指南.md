# 环境搭建指南

> 目标：新成员 15 分钟内能在本机跑起来 Growth 项目并提交第一个改动。
> 引擎：Godot 4.7（stable） · 语言：GDScript · 平台：Windows / macOS / Linux

---

## 1. 必装组件

### 1.1 Godot 编辑器
1. 下载 **Godot 4.7 stable**（标准版即可，本项目用 GDScript 不依赖 mono）：
   - 官方：<https://github.com/godotengine/godot/releases>
   - 选 `Godot_v4.7.x-stable_win64.exe`（Windows）/ 对应平台包。
2. 解压到任意目录，例如 `C:\Godot Engine\`。
3. VS Code 已配置 `.vscode/settings.json` 指向编辑器路径，如不一致请改：
   ```json
   { "godotTools.editorPath.godot4": "c:\\Godot Engine\\Godot_v4.7.x-stable_win64.exe" }
   ```

> 本项目 `project.godot` 中 Windows 渲染设备设为 `d3d12`；macOS / Linux 会自动回退到 Vulkan，无需手动改。

### 1.2 Git & Git LFS
1. 安装 Git：<https://git-scm.com/downloads>
2. 安装 Git LFS：<https://git-lfs.github.com/>
3. 验证：
   ```powershell
   git --version          # >= 2.40
   git lfs version        # >= 3.x
   ```

### 1.3 VS Code（推荐 IDE）
- 安装 VS Code：<https://code.visualstudio.com/>
- 推荐插件（在 VS Code 扩展市场搜）：
  - **GDScript**（godot-tools，Geometric Hunting）
  - **EditorConfig**
  - **GitLens**（可选）
  - **Markdown All in One**

> 也可直接用 Godot 内置编辑器，但团队规范建议 VS Code + GDScript 插件。

## 2. 拉取项目

```powershell
git clone https://github.com/YICIYUAN-GAME-DEPARTMENT/Growth.git
cd Growth
git lfs install        # 首次使用 LFS 必执行一次
git lfs pull           # 拉取所有 LFS 资源
```

> 若 `git lfs pull` 卡住或失败，多半是网络问题，可改用 SSH 或挂代理重试。

---

## 3. 打开项目

### 3.1 用 Godot 编辑器
1. 双击 `Godot_v4.7.x-stable_win64.exe`。
2. 在项目管理器点 **Import** → 选 `D:\Programs\Growth\project.godot`。
3. 首次打开会扫描并导入资源，等待右下角进度结束。
4. 按 **F5** 运行；应进入 `Main.tscn`（黑色画布，无报错即正常）。

### 3.2 用 VS Code
1. 用 VS Code 打开 `D:\Programs\Growth` 文件夹。
2. 安装 GDScript 插件后，`Ctrl+Shift+P` → `Godot: Open Project with Editor`（需先在 settings.json 配好编辑器路径，§1.1）。
3. 或直接在终端：
   ```powershell
   & "C:\Godot Engine\Godot_v4.7.x-stable_win64.exe" --path "D:\Programs\Growth"
   ```

## 4. 常见问题

| 现象 | 处理 |
|------|------|
| 运行报"Autoload 脚本找不到" | 确认 `Scripts/Autoload/*.gd` 存在（应已在仓库内） |
| 贴图/音频显示破损 | `git lfs pull` 未完成，重跑 |
| `.tscn` 改动冲突 | **不要手合并**，用 Godot 编辑器打开解决 |
| 提交被拒（pre-commit） | 检查是否误把 `.godot/` 加入暂存 |
| Godot 卡在导入循环 | 删除 `.godot/` 目录后重新打开项目 |
